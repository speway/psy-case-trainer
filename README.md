# Тренажёр профессионального мышления психолога

Учебная платформа Научного сектора психологии ТФ МГУ: документированные кейсы, методика КАРТА, база знаний, источники и локальный профиль компетенций.

## Запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
npm start
```

## Публикация

Проект рассчитан на автоматическую публикацию в Vercel из ветки `main`.
